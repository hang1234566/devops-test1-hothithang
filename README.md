# DevOps Test 1

Website thực hành quy trình CI/CD tự động.

## Công nghệ sử dụng
- GitHub: quản lý source code
- Jenkins: tự động hóa pipeline
- HTML/CSS: xây dựng giao diện website
- Cloudflare Pages: triển khai website
- Telegram Bot: gửi thông báo trạng thái deploy

## Quy trình CI/CD
Developer -> GitHub -> Jenkins -> Build -> Deploy -> Telegram

## Mục tiêu
Tự động build và triển khai website khi developer push code lên nhánh main.
